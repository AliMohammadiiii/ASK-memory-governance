# Fixes 2026-07-08 — v4-run (lme_m 100–129) failure analysis remediation

Source analysis: `runs/lme_m_openrouter_qwen_gemma_minilm_100_129_seed0_v4/ANALYSIS_fa.md`.
The run scored 17/30 (56.7%). Root causes: 4 judge-guard false negatives,
4 extraction/retrieval evidence losses, 4 no-CoT arithmetic failures,
1 pipeline-injected wrong answer (conflict block). All are addressed below.

## Changes

### 1. Judge: gold-token-guard exemptions — `src/ksa/eval/longmemeval.py`
Hard rejection now only fires on genuine value mismatches:
- **Subset exemption**: prediction tokens ⊆ gold tokens ("University of
  Melbourne" vs gold "University of Melbourne in Australia", "GR-90" vs
  "The GR-90 trail.") → defers to the LLM judge.
- **Morphological coverage**: every missing gold token has a ≥5-char-prefix
  variant in the prediction ("photos" covers "photography") → defers.
- Numeric mismatches ("2" vs "3", "24-70mm" vs "70-200mm") and wrong sibling
  values ("long-grain" vs "short-grain") still hard-reject with no judge call.

Verified against the real v4 judgments: sessions 3b6f954b, 4100d0a0, 488d3006,
5025383b now defer to the judge; 3a704032, 4f54b7c9, 41698283 still hard-reject.

### 2. Answerer: two-stage WORK/FINAL contract (visible CoT) — `src/ksa/pipeline/orchestrator.py`, `src/ksa/baselines/prompts/controller_cot.j2`
The v4 answers averaged 2–7 completion tokens: provider reasoning was disabled
and the prompt demanded a bare span, so the 9B model failed every aggregation
(416+440=856 → "Unknown", 24-day date diff → "Unknown", 5-item count → "4").
Now the model reasons in a bounded WORK section (quote evidence + dates,
enumerate, do arithmetic) and ends with `FINAL: <short answer>`;
`_extract_final_answer()` parses it (variants + truncation fallbacks). The
Unknown-retry triggers on the PARSED final answer and its system prompt asks
for explicit enumeration. New template `controller_cot.j2` (the shared
`recency_pruning.j2` is untouched for other baselines). `max_new_tokens`
512→768 and `_MAX_RESERVED_OUTPUT_TOKENS` 512→768 so CoT never truncates
before FINAL. Raw completions are kept in `extras.answer_raw_text` for audit.

### 3. Conflict block de-fanged — `src/ksa/pipeline/orchestrator.py::_conflict_block`
The old block greedily paired two same-slot items and asserted "the value from
the MOST RECENT date is the correct, current one" — on session 41698283 it
crowned the older 24-70mm lens while the true newest evidence (70-200mm,
2023-08-30) sat outside the pair, directly injecting the wrong answer. Now:
question-anchor gating (off-topic numeric pairs never surface), cluster
completion (all same-slot items join the group before sorting), and neutral
wording with no winner verdict.

### 4. Compute-intent gaps — `src/ksa/controller/computation.py`
- "how many days had passed **since** X when Y" → `DATE_DIFF` (previously
  required the word "between"; session 4dfccbf7 fell to COUNT_EVENTS).
- Implicit sums over a counted set: "the page count **of the two** novels"
  → `NUMERIC_SUM` (session 37f165cf classified as NONE).
- Existing classifications are regression-pinned (last-month counts, between
  date-diffs, hours-per-week counts, relative-time).

### 5. Extraction: episodic events in scope — `prompts/extraction_v_final3.j2`, default flipped in `scripts/run_baseline.py`
The v4 extractor dropped ALL turns of the Ford-F-150 sessions ("describes
current activity … no durable preferences"), the third plant ("plan/intention"),
trip durations, and the turbinado-sugar experimentation — the answers were
unrecoverable no matter the retriever. v_final3 (based on v_final2) adds an
explicit in-scope section: current projects/activities, acquisitions with
counts, trips + durations, started/stopped routines, self-quantities — with
examples mirroring the observed failures. Pure questions/hypotheticals stay out
of scope.

### 6. Retrieval recall — `src/ksa/pipeline/orchestrator.py::_append_lexical_complement`, `scripts/run_vllm_cascade.py`
- IDF lexical complement: cap 3→8 and assistant-role items participate at 0.7
  weight (exact-term evidence like "turbinado"/"F-150" that MiniLM misses).
- Dense seeds `--retrieval-k` 12→16 (prompt budget has ample headroom:
  ~15K/32K tokens at k=12 in v4).
