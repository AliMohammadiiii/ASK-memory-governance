\section{Standing rules}\label{standing-rules}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Lead with N04--N05 before any policy score.
\item
  Never headline the 0.9222 full-corpus reference score.
\item
  Distinguish action false commit from state invalid commit.
\item
  Attach the finite-sample upper bound and missed-update count to any
  zero-event statement.
\item
  Use family/minimal-pair clustering; item-level tests are secondary.
\item
  Do not call a null result equality, matching, equivalence, or
  non-inferiority.
\item
  Keep external mappings, incomplete runs, and contaminated downstream
  evidence outside primary comparisons.
\item
  Do not imply that v3 independent data, three-human annotation, or long
  trajectories have been executed.
\end{enumerate}
