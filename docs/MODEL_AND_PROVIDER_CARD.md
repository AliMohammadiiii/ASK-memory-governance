# Model and provider card

Every model-backed result must report requested and actual model identity,
provider/endpoint class, revision if available, decoding, seed, prompt hash,
tool/parser versions, retries, fallback routing, failures, and cost accounting.
Provider aliases without a returned immutable revision are a reproducibility
limitation.

No paid inference is authorized by the repository. Provider-output
redistribution is blocked until `release/MODEL_OUTPUT_RIGHTS.md` is resolved.
The current model-family matrix is prospective and marked not run.
