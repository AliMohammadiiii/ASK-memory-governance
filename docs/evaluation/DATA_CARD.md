# Data card

MGP-6 is author-created synthetic diagnostic data for Keep/Supersede/Abstain
memory-governance decisions. V4.3 is the current controlled diagnostic; v2 is
retained because its shortcut-rejection/construct-validity gate failed. Neither
version is a representative population sample, naturally occurring interaction
corpus, or established community benchmark.

Public/private boundaries, license status, independent-annotation limitations,
and external LongMemEval restrictions are in `release/DATA_PROVENANCE.md`,
`release/PUBLIC_PRIVATE_MATRIX.csv`, and `LICENSE-DATA.md`. V4.3 redistribution
is currently blocked pending an explicit human/legal decision.
