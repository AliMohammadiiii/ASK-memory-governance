## Required metadata fields

Every machine inventory row contains: logical name, relative path, type, owner,
source, generating command, configuration ID, input hashes, output hash,
visibility, model-facing status, consumed status, paper-reference status,
reproducibility class, and known problems. Unknown provenance is recorded as
`unknown`, never inferred as verified.
