# Bibliography audit notes

The consolidated bibliography is `../references.bib`. It supports the Markdown citation keys used by `../MASTERS_THESIS_KSA_MGP6.md`.

## Current checks

- Citation-key completeness is checked mechanically: every `[@key]` in the thesis must have a matching BibTeX key.
- Duplicate BibTeX keys are prohibited.
- The bibliography is not yet formatted to an official University of Tehran style.
- Entries whose complete author metadata was not verified retain an explicit `note` rather than invented details.

## Human verification still required

Before institutional submission, verify each cited work against its primary publication page or official proceedings record:

1. complete author order and spelling;
2. exact title and capitalization;
3. venue, volume, issue, pages, and year;
4. DOI, anthology identifier, or stable URL;
5. preprint-to-published-version replacement where applicable; and
6. consistency with the University's required bibliography style.

The thesis's novelty boundary does not depend on a primacy claim. The related-work section positions KSA as operationalizing and evaluating a combined write-policy and layered-measurement design.
