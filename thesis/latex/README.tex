\section*{Source map}
\begin{itemize}
  \item \texttt{main.tex}: University of Tehran template entry point.
  \item \texttt{frontmatter/}: verified administrative metadata and bilingual abstracts.
  \item \texttt{chapters/}: the ten manuscript chapters generated from the retained review source.
  \item \texttt{appendices/}: thesis appendices plus the approved Persian supporting text.
  \item \texttt{support/}: converted review/checklist/Word materials; not part of the submitted manuscript.
  \item \texttt{tools/build\_sources.py}: deterministic Markdown/DOCX-to-TeX conversion.
  \item \texttt{tools/build.sh}: build entry point. Run it from any directory.
\end{itemize}
