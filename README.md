# ASK: Auditable Memory Governance Protocol

ASK is a storage-agnostic protocol and state-transition contract for auditable
memory revision in long-lived AI systems. A controller or policy proposes one
of **KEEP**, **SUPERSEDE**, or **ABSTAIN**; ASK records sufficient evidence and
configuration identity, applies deterministic transition semantics, preserves
provenance and supersession lineage, and supports replay and invariant checks.
The controller is one component of ASK, not the whole contribution.

This repository is both a Python package and a research artifact. The maintained
runtime lives under `src/ask`; benchmark protocols, recorded evidence, paper and
thesis sources, and historical experiment material are kept in clearly separated
directories.

## Release status

- Package version: `0.2.0`
- Supported Python: 3.11 and 3.12
- Default verification: offline and credential-free
- External model and LongMemEval runs: opt-in; data and credentials are not
  redistributed
- Scientific scope: MGP-6 v4.3 is the current controlled hidden diagnostic;
  MGP-6 v2 remains a disclosed construct-validity failure and is not primary
  capability evidence
- LongMemEval: the homogeneous V12 outputs support a 137/180 controller result
  versus 114/180 naive overwrite, but the run remains `final_candidate` because
  historical finalization and clean-provenance defects cannot be repaired
  retrospectively
- MGP-Natural v0.2.2: its construction software is vendored under
  `third_party/mgp-natural-v0.2.2/`; the supplied StudyChat and WikiConv
  workspace is private, derivative-only, and quarantined with no gold,
  release clearance, or paper result
- Publication readiness: generated by `scripts/check_readiness.py`; templates,
  scaffolds, or the existence of a manuscript never satisfy a gate

The current scientific interpretation is maintained in
`docs/audit/SCIENTIFIC_SOURCE_OF_TRUTH.md`. The documentation map and precedence
rules are in `docs/README.md`.

## Advisor review

Start with `docs/development/ADVISOR_START_HERE.md`. It gives a short reading
order for the manuscript, protocol contribution, evidence ledger, and publication
blockers. The complete offline review gate is:

```bash
make advisor-check PYTHON=.venv/bin/python
```

To create a sanitized local snapshot for a supervisor without copying the
working directory or private evidence, run:

```bash
make advisor-package PYTHON=.venv/bin/python
```

The generated archive is written under `advisor_handoff/`, which is ignored by
Git. It includes the current Git-visible candidate files and the compiled paper,
but excludes private data, local run trees, historical path-mapping records,
application materials, and generated caches. It is a review snapshot, not a
publication-ready release and not evidence that the publication gates passed.

## Quick start

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
make check
make verify-claims
make readiness
```

The equivalent one-command environment bootstrap is:

```bash
bash scripts/setup_venv.sh
source .venv/bin/activate
```

Run the complete offline engineering gate before considering a release:

```bash
make release-check
```

Heavy and document-generation dependencies are optional:

```bash
python -m pip install -e '.[ml]'         # model-backed experiments
python -m pip install -e '.[schema]'     # schema regeneration
python -m pip install -e '.[documents]'  # DOCX builders
```

## Reproducibility

The offline path requires no secrets or external datasets:

```bash
make repo-check
make test
make lint
make typecheck
make validate-data
make build
make inventory
make verify-manifest
make validate-traces
make readiness
```

Use `docs/reproducibility/README.md` for environment and provenance rules,
`docs/architecture/ASK_PROTOCOL.md` for the protocol contract, and
`docs/reproduce_results.md` for benchmark-specific commands. Generated runs,
caches, local databases, compiled publications, and handoff ZIPs are ignored and
must not be added back to the source tree.

## Hosted runs

The repository never embeds credentials. Load newly authorized credentials
from an approved secret manager into the current shell. Keep private benchmark
input under the ignored private-data directory:

```bash
export LONGMEMEVAL_DATA="${PWD}/.private/longmemeval/longmemeval_s_cleaned.json"
```

Do not pass secrets as CLI arguments; shell histories and run manifests can
capture them. The active model configuration is
`configs/models/openrouter_qwen_gemma.yaml`.

## Release building

`scripts/release/build_final_release.py` builds the private academic handoff and
a separately sanitized public repository. It reads only Git-tracked public
candidates and refuses a dirty worktree by default:

```bash
python scripts/release/build_final_release.py
```

`--allow-dirty` exists only for local validation builds and should not be used to
publish a release.
