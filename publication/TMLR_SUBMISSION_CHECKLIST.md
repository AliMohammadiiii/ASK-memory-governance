# TMLR submission checklist

Status: `BLOCKED_HUMAN_DECISION`

- [ ] Read the current author guide, editorial policies, ethics guidelines, and
  code of conduct on the submission day.
- [ ] Freeze final authorship and obtain consent from every author.
- [ ] Verify every author's active, complete OpenReview profile.
- [ ] Compile with the unmodified official TMLR style.
- [ ] Run anonymous scan on manuscript, metadata, PDF properties, supplements,
  repository links, acknowledgements, and file names.
- [ ] Confirm no prohibited dual submission or archival overlap.
- [ ] Complete human-subjects/IRB, funding, competing-interest, and COI fields.
- [ ] Resolve data, annotation, model-output, and third-party redistribution.
- [ ] Run clean reproduction and claim verification from the frozen release.
- [ ] Confirm the CC BY 4.0 submission license is acceptable to every author.
- [ ] Upload only the frozen, hashed PDF and anonymous supplement.
