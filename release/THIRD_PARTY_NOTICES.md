# Third-party notices

Status: `BLOCKED_HUMAN_LEGAL_DECISION`

The software dependency declarations in `pyproject.toml` identify packages but
do not constitute a complete redistributable notice bundle. Before release,
generate a dependency/license inventory in the clean build environment, review
all licenses and attribution obligations, and attach exact versions and source
URLs. LongMemEval, model-provider outputs, external memory systems, model
weights, and independently produced annotations require separate review and
are excluded by default.

The MGP-Natural v0.1.0 parent contains text derived from Wikipedia editorial
discussion pages. The archive itself is excluded. Any later redistribution must
pin source revisions, preserve required attribution, identify modifications,
apply the applicable share-alike terms, and complete privacy review. The
repository currently retains only cryptographic parentage and aggregate audit
receipts.
