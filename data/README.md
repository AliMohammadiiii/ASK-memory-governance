# Data

- `mgp6_v1_seed0.jsonl` is a deterministic 60-row compatibility fixture generated from the frozen MGP-6 v2 package for legacy tests. It is not the authoritative benchmark release.
- The authoritative MGP-6 v2 dataset is under `benchmarks/mgp6/data/`.
- LongMemEval data is intentionally not redistributed. Follow `benchmarks/longmemeval/README.md` and provide it locally.
- Large historical model outputs are excluded from Git and represented by manifests under `artifacts/manifests/`.
