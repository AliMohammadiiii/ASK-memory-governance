# Contributing

1. Create a branch from `main`.
2. Install with `make setup`.
3. Run `make test`, `make lint`, `make typecheck`, and `make repo-check`.
4. Add regression tests for behavior changes.
5. Do not commit credentials, private conversations, model caches, or large run outputs.
6. Record benchmark-affecting changes in `CHANGELOG.md` and `DECISION_LOG.md`.
