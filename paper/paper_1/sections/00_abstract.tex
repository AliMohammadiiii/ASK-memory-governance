\begin{abstract}
Persistent memory turns an agent's interpretation of one interaction into state
that can affect many later sessions. Final-answer accuracy does not identify
whether a failure arose when the agent formed a candidate, governed its write,
mutated the store, retrieved stale state, or generated an answer. We introduce
ASK, a storage-independent governance contract placed before persistent-memory
mutation. Given a memory state, a candidate update, and attributable evidence,
an ASK controller proposes \keep, lineage-preserving \supersede, or
write-time \abstain. A separate transition layer applies the proposal subject
to state and lineage invariants, while decision records retain the information
needed to reconstruct the implemented policy. ASK is a protocol, not one
classifier, prompt, database, or benchmark.

We evaluate complementary parts of this contract, using two instruments that
answer different questions and neither of which is the contribution itself.
Executable tests check the
reference transition semantics. \mgpc{} is a controlled synthetic diagnostic
built for this paper to make the write decision observable in isolation, with
$900$ items in $100$ component-disjoint semantic groups. On its sealed
$540$-item hidden split, one configuration frozen before scoring reaches
$0.8481$ action accuracy and $0.8479$ macro-F1, with component-cluster $95\%$
intervals of $[0.8037,0.8889]$ and $[0.8021,0.8894]$. Of $38$ errors on
gold-\abstain{} items, $30$ preserve the modeled state, while $8$ incorrectly
supersede an active record. A separate $180$-item \lme{} run evaluates the
long-memory pipeline without per-write gold labels. Governed writes obtain
$137/180$ correct downstream answers, compared with $114/180$ for naive
overwrite. Exact replay reproduces all $12{,}654$ logged controller decisions,
which establishes execution fidelity rather than write correctness.

Together the two instruments support explicit write governance, auditable
supersession, and layer-specific failure attribution: the diagnostic supplies
write labels without realism, the downstream run supplies realism without write
labels. Neither establishes deployment safety or population generality. The
controlled diagnostic is synthetic, the downstream run uses one fixed slice and
model configuration, the generic reference validator is not wired into that
runtime's SQLite mutation path, and a planned natural-dialogue track remains
quarantined without independent gold. We state these boundaries because the
claim is about the governance contract, not about a score on either instrument.
\end{abstract}
