# Paper workspace

This folder is intentionally source-first. Select the current official venue template before generating a submission PDF. The defensible paper strategy is one coherent ASK/MGP-6 paper unless preference-binding experiments become an independently validated contribution.

Use `research/deep_research_report.md`, `research/LITERATURE_POSITIONING.md`, the machine-readable experiment registry, and generated result tables. Do not copy unverified headline numbers from historical Markdown reports.
