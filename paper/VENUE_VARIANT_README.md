# Venue-variant status

The canonical manuscript is complete, but no venue-specific source tree is
claimed here because the author has not selected a submission venue and the
official template must be taken from that venue at submission time.

Use `PUBLICATION_STRATEGY.md` to choose the route. The preferred route is the
next suitable ARR cycle, with an EACL commitment only if the chosen cycle and
commitment dates remain compatible; TMLR is the fallback. Once selected, copy
the canonical source into the official current template, preserve the evidence
labels, and rerun the checklist and PDF QA. Do not alter the scientific status
of the incomplete six-shot or LongMemEval rows to fit a venue table.

This directory in the release therefore contains the strategy and this explicit
gate rather than a fabricated or potentially outdated template variant.
