\section{Conclusion}
\label{sec:conclusion}
We described an interface that names three decisions about a proposed memory write and records each decision with the features, scores, thresholds and identifiers needed to recompute the action, and we reported what the available evidence supports. One configuration frozen before scoring reached an action accuracy of 0.848 on a controlled synthetic diagnostic whose labels depend on which sentences the dialogue indexes (verified on the public components). An exploratory controller-only run on LongMemEval-M scored 128 correct answers on the grader's output (137 after nine one-sided manual adjudications), and its merged 12\,654-row decision log is recomputed exactly at the decision-rule level, with 822 of the rows replayed from stopped runs. The reference protocol is a specification first committed after the LongMemEval run and the MGP-6 hidden evaluation, with a baseline validator that accepted non-conforming states, a corrected validator supplied as a patch, and no persistence layer. The main open work is a matched comparison under one configuration on a fresh slice and an evaluated system that runs through the reference protocol.
