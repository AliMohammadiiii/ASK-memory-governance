\begin{abstract}
Long-term agent memory is usually evaluated by final-answer accuracy, which mixes write-decision quality with extraction, retrieval, answering and judging. We describe ASK, an interface that makes the write decision explicit as one of three actions (\keep, \supersede, \abstain) and records each decision with the features, scores, thresholds and identifiers needed to recompute the action. We keep the evidence streams separate. MGP-6 v4.3 is a controlled synthetic decision diagnostic in which the action depends on which two of six pooled sentences the dialogue indexes (verified on the 40 public components); one configuration frozen before hidden scoring reached 0.848 action accuracy on 540 hidden items. An exploratory controller-only LongMemEval-M run on 180 questions scored 128 correct on the grader's output (137 after nine one-sided manual adjudications), and its merged decision log of 12\,654 rows is recomputed exactly from the logged features. A separate 2 $\times$ 2 diagnostic contrast on the public development split, run with five substitute configurations of three models, found accuracy differences associated with evidence routing and with the prompt that differ among configurations and, for the Gemini settings, depend on how replies are parsed. We make no comparative downstream or priority claim. The reference protocol was first committed after both evaluations and is not used by any evaluated system; its baseline validator accepted all 19 tampering probes we built, and we supply a corrected validator as a patch. It is a specification, not conformance evidence.
\end{abstract}
