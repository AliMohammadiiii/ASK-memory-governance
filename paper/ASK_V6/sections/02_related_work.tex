\section{Related work}
\label{sec:related}
We group comparators by function and limit each description to what its text, or its released code where we inspected it, establishes. Works marked $^{\dagger}$ were surfaced only by the targeted search and screened against four elements.

\paragraph{Write-time admission and gating.} A-MAC admits an extracted candidate when a weighted feature score reaches a threshold, and it describes an update path that removes a conflicting memory and inserts a merged one \citep{arxiv_2603_04549}. SSGM proposes a write validation gate that rejects proposed changes contradicting protected core facts, as a conceptual architecture without an implementation \citep{arxiv_2603_11768}. Persona commits a tentative persona update only when a specification checker finds no hard violation, and otherwise rolls back to the last verified state \citep{persona_symmetry_2026}. Memory-R1 trains a manager over ADD, UPDATE, DELETE and NOOP operations, and a MemGuard framework for memory contamination assigns ADD, UPDATE or SKIP to each memory atom \citep{arxiv_2508_19828,arxiv_2605_28009}. The CUPMEM prototype in STALE adjudicates whether a stored state is kept, archived, replaced or marked as unknown \citep{arxiv_2605_06527}. Persona (rollback) and A-MAC (rejection) implement no-commit outcomes, whereas the unknown marker in CUPMEM is itself a write, a deferred candidate in TARL enters a pending ledger, and MemTX records quarantined candidates with a reason \citep{persona_symmetry_2026,arxiv_2603_04549,arxiv_2605_06527,arxiv_2608_03699,arxiv_2607_23929}. Selective Memory$^{\dagger}$, When Not to Write Memory$^{\dagger}$ and MemReader$^{\dagger}$ also make write-time decisions with archive, needs-review and deferral outcomes \citep{arxiv_2603_15994,arxiv_2607_02579,arxiv_2604_07877}.

\paragraph{Supersession and belief revision.} Graph-native cognitive memory keeps immutable revisions linked by SUPERSEDES edges and relates its revision operator to AGM belief-base postulates \citep{arxiv_2603_17244}. TOKI adjudicates contradictions with typed operators over a bitemporal fact table and writes the losing fact to an audit row \citep{arxiv_2606_06240}. SodaMem applies a deterministic slot rule that closes the older fact's validity interval and writes a SUPERSEDES edge \citep{arxiv_2608_08055}. GPM and the verifier-persisting MemGuard retain replaced records with supersedes links, and ECHO keeps a revision relation over typed bitemporal records \citep{arxiv_2608_12476,arxiv_2608_21867,arxiv_2608_21755}. In Governed Shared Memory a detector sets the supersedes link asynchronously after commit \citep{arxiv_2606_24535}, and in MemTX the superseded record has no successor-to-predecessor edge in code \citep{arxiv_2607_23929}. Adjacent works concern revocation of stored precedents \citep{arxiv_2608_07429}, eviction after unconditional storage \citep{arxiv_2606_03463}, or the memory-update gap \citep{arxiv_2606_27472}.

\paragraph{Transactional and event-sourced memory and logs.} MemTX stages beliefs through a fixed lifecycle with ordered commit checks and machine-checked invariants \citep{arxiv_2607_23929}. TARL separates a learned action predictor from a deterministic executor that acts on accepted, pending and rejected ledgers \citep{arxiv_2608_03699}. Quipu stores signed allow, deny and unknown verdicts with an evidence hash and replays recorded decisions as of a past instant, with a stated limit for denials \citep{arxiv_2608_16813}. The Log is the Agent derives graph state from an append-only event log and distinguishes strict from permissive replay, but it does not govern memory writes \citep{arxiv_2605_21997}. ESAA$^{\dagger}$ replays a hash-verified event log, MemLineage$^{\dagger}$ stores per-write source and context hashes in a Merkle log, and SuperLocalMemory 4.0$^{\dagger}$ writes a hash-chained audit trail atomically with the fact row \citep{arxiv_2602_23193,arxiv_2605_14421,arxiv_2608_08253}.

\paragraph{Governance, lineage and provenance.} MGP specifies a storage-independent and runtime-independent protocol for governed memory writes, with candidate objects, merge hints and an audit sink, and it leaves the write decision to the caller \citep{mgp_hkuds_2026}. GPM binds policy and normalizer versions and the ledger head into its decision records for claim release \citep{arxiv_2608_12476}, and TOKI pins the decoder tuple that keys its stored judge log \citep{arxiv_2606_06240}. Eywa accepts an extracted fact only after checks against its source text and writes it with a link to immutable evidence \citep{arxiv_2605_30771}. Several close neighbors govern other objects: claim release (GPM), policy compliance of writes (Quipu), persona state (Persona), commit discipline for agent actions (MemTX) and read-time currentness (ECHO) \citep{arxiv_2608_12476,arxiv_2608_16813,persona_symmetry_2026,arxiv_2607_23929,arxiv_2608_21755}.

\paragraph{Evaluation resources and benchmarks.} HaluMem separates extraction, update and question-answering evaluation and inspects stored memory directly \citep{arxiv_2511_03506}. MemOps supplies gold lifecycle operation traces but scores them through probe answers rather than against executed write actions or persisted state \citep{arxiv_2607_12893}, and MemTrace separates retrieval reach from evidence use \citep{arxiv_2606_17328}. TARL provides human five-way action labels derived from long-memory benchmarks together with exact next-state accuracy \citep{arxiv_2608_03699}, and MCB is a synthetic benchmark of the decision to persist, use temporarily, verify or ask for clarification \citep{arxiv_2608_19564}. CPB$^{\dagger}$ scores admission policies, including an explicit abstain action, against fixed gold actions, and MemTxn$^{\dagger}$ reports admission audit, state recovery and downstream F1 separately \citep{arxiv_2609_30813,arxiv_2607_27834}.

\paragraph{Scope of the comparison.} \ask{} specifies its three-action decision and decision record in a reference protocol that was written after the reported evaluations and is not called by the evaluated systems. Within a documented review of 30 full-text comparators, 12 search-surfaced candidates and 112 targeted search iterations (five of which returned no records because a source failed), whose search record is released, we did not identify a system for persistent LLM-agent memory that implements all of the following: a three-way keep (non-superseding), supersede (lineage-preserving replacement) or abstain (no commit) write decision whose abstention leaves state unchanged; lineage-preserving replacement; per-decision configuration and evidence identity; a declared replay scope; and separate reporting of action-label and downstream evidence. The 12 search-surfaced candidates were coded on four elements, so the conjunction was assessed for them at that coarser level. This is a bounded result relative to the documented search iterations and not a claim that no such system exists. Each element of \ask{} has prior or concurrent precedent in the works discussed here, and this paper therefore makes no priority claim.
