# بسته اجرایی انسانی MGP-6 v3

نسخه: ۳.۰, ۱۴۰۵/۰۴/۲۴

این پوشه، متن‌های آماده برای اجرای مستقل ساخت داده، برچسب‌گذاری سه‌نفره و داوری MGP-6 v3 را نگه می‌دارد. وضعیت پروتکل v3 همچنان «طراحی پیش‌ثبت‌شده و اجرا‌نشده» است؛ وجود این بسته به‌تنهایی هیچ ادعای تجربی جدیدی ایجاد نمی‌کند.

## قانون توزیع

راهنمای هماهنگ‌کننده محرمانه است و نباید کامل برای مشارکت‌کنندگان فرستاده شود. هر فرد فقط این دو فایل را دریافت می‌کند:

- فایل دستورالعمل نقش خودش؛
- رضایت‌نامه مشارکت‌کننده.

نویسندگان داده، برچسب‌زن‌ها و داور نهایی نباید به خروجی سیستم‌ها، برچسب‌های دیگران، منطق کنترل‌گر یا بسته نقش‌های دیگر دسترسی داشته باشند.

## فایل‌ها

- `00_COORDINATOR_GUIDE_FA.md`: راهنمای کامل اجرا و توزیع؛ فقط برای هماهنگ‌کننده.
- `01_WRITER_INSTRUCTIONS_FA.md`: دستورالعمل نویسندگان داده.
- `02_ANNOTATOR_INSTRUCTIONS_FA.md`: کتابچه برچسب‌گذاری مستقل.
- `03_ADJUDICATOR_INSTRUCTIONS_FA.md`: دستورالعمل داور چهارم و حل اختلاف.
- `04_PARTICIPANT_CONSENT_FA.md`: فرم رضایت، حریم خصوصی و اجازه بازتوزیع.
- `forms/`: الگوهای CSV برای تحویل و ثبت ممیزی.
- `a11y_reports/`: گزارش‌های ماشینی آخرین ممیزی دسترس‌پذیری.
- `dist/`: خروجی محلی و تولیدی DOCX؛ در Git نگهداری نمی‌شود.

## ساخت خروجی DOCX

از ریشه مخزن اجرا کنید:

```bash
python3 -m pip install -e '.[documents]'
python3 benchmarks/mgp6/v3_human_pack/build_human_pack_docx.py
```

خروجی‌ها در `dist/` ساخته می‌شوند. فایل‌های preview، PDF و ZIP خروجی build
هستند و نباید به source tree برگردند.

## اطلاعات خصوصی پیش از ارسال

هماهنگ‌کننده باید نام پروژه و دانشگاه، راه ارتباطی مسئول، حجم و مهلت کار،
پرداخت، مسیر امن تحویل و تاریخ نهایی انصراف یا حذف اطلاعات را در برگهٔ
توزیع خصوصی هر دوره ثبت کند.

هیچ فرم امضاشده یا شناسه واقعی مشارکت‌کننده نباید داخل مخزن عمومی قرار گیرد.
